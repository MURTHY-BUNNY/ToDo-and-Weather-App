DAY 10 — VANILLA JAVASCRIPT PROJECTS

Projects included:
- todo-app: add, edit, delete, complete and filter tasks. Uses localStorage.
- weather-app: search a city and view current weather using Open-Meteo (no API key).

OPEN IN VS CODE
1. Extract the ZIP.
2. Open the extracted Day-10-Vanilla-JS-Projects folder in VS Code.
3. Open todo-app/index.html or weather-app/index.html.
4. Right-click the HTML file and select Open with Live Server.
5. Do not run script.js with Node. These are browser applications using document, localStorage and fetch.

WEATHER APP
Requires an internet connection. Open-Meteo provides the geocoding and current weather data.

DEPLOYMENT
Deploy todo-app and weather-app as two separate static sites. For example, upload each project folder separately to Netlify Drop, or publish each folder through its own GitHub Pages repository.
